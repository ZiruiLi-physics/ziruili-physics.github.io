# 研究兴趣

## 主要活跃方向

- **非晶固体中的几何与拓扑缺陷** — 利用几何和拓扑方法理解无序固体和玻璃的塑性、弹性及结构性质
- **非平衡量子多体动力学** — 驱动量子系统远离平衡态的动力学、弛豫和热化现象
- **无序固体中的经典随机热力学** — 非晶和玻璃系统中的随机动力学、记忆效应与能量景观

## 其他方向

- 多体局域化（MBL）与本征态热化假说（ETH）
- Floquet 系统与离散时间晶体
- 张量网络方法（DMRG、精确对角化）
- 开放量子多体系统与 Lindblad 动力学
- 非平衡统计物理

## 更广泛的兴趣

- 量子混沌（SYK 模型、黑洞信息）
- 量子力学基础理论
- 元胞自动机与神经网络

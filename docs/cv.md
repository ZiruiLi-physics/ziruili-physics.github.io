# 简历

<p class="zl-meta">最后更新：2026-10</p>

## 研究兴趣

- **理论物理**：主要集中在凝聚态与统计物理，以理论和数值计算为主；也涉猎过高能物理的计算与理论。
    - 凝聚态与统计物理：开放量子多体系统、局域化与热化（MBL、ETH、时间晶体）、无序固体（颗粒与玻璃体系）、Floquet 系统、张量网络。
    - 高能理论与引力：格点 QCD、量子混沌（SYK 模型、黑洞）。
    - 其他：量子力学基础理论。
    - **目前在研**：非晶固体中的几何与拓扑缺陷；非平衡量子多体动力学；无序固体中的经典随机热力学。
- **计算机**：元胞自动机、神经网络。
- **二次元**：动画、Vocaloid、Vtuber。

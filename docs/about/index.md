# 关于我

我是李梓瑞，上海交通大学物理与天文学院理论物理博士生，在 Wilczek 量子中心（WQC）做研究。

本科就读于北京航空航天大学物理学院核科学与技术系。期间担任《理科数学分析进阶》助教，在锦屏地下实验室 JUNA 项目组实习，并参与《北航物理评论》特刊的编辑。

研究之外，我喜欢动画、游戏和音乐。

## 研究

真实凝聚态体系中的统计现象。具体包括无序固体的几何与拓扑缺陷、非平衡量子多体动力学、经典随机热力学和量子热化。完整列表见[研究页](../research.md)。
